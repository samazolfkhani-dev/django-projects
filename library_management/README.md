### 📚 Library Management System

A web-based library management system built with Django and PostgreSQL.

**Main technologies:**

* Python
* Django
* PostgreSQL
* HTML / CSS
* Git & GitHub

**Current features:**

* User authentication
* Book management
* User profiles
* Search
* Database management
* ...
